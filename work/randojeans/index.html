01 / The idea

A real store, not a tutorial cart

I wanted a project that covers everything a small online shop actually needs — not just a product list and a cart, but payments, discount codes, order tracking, returns, reviews, emails and an admin panel to run it all.

It's built on the newest Laravel stack: Laravel 13, Livewire 4 single-file page components for every customer-facing page, and Filament 5 for the admin side.

02 / For customers

The shopping side

Product pages

Full-bleed image gallery, a lightbox with zoom and pan, and size selection by waist and inseam that only offers combinations in stock.

Cart & checkout

Discount codes, free shipping over $150, GST worked out on the total, then payment on Stripe's secure checkout page.

Accounts

Registration, email verification, password reset, saved addresses, order history, a wishlist and account deletion requests.

After the sale

Order emails at every step, a PDF invoice, return requests within 30 days, and product reviews.

04 / After checkout

Every status change does something

An order moves through pending → paid → ready to ship → shipped → delivered. Model events watch for each change, stamp the time it happened and send the matching email, so the admin only ever has to update one field.

  • Shipped orders get a direct tracking link for supported carriers, such as Australia Post.
  • Seven days after delivery, a scheduled command emails a review reminder — once per order.
  • Delivered orders can be returned within 30 days. Admins approve or reject the request, and the customer is emailed either way.
  • New reviews and return requests notify the admins by email.

06 / Security & reliability

Guarding the places that matter

Card-testing guard

Checkout is rate-limited per IP (8 attempts per 10 minutes) to stop scripted attempts with stolen cards.

No double orders

An atomic cache lock per session means a fast double-click can only ever create one order.

Verified webhooks

Every Stripe webhook's signature is checked before an order can be marked as paid.

Brute-force limits

Login, discount codes and email-verification links are all throttled, and verification links are signed.

07 / How it's built

Modern Laravel, kept tidy

  • Every storefront page is a Livewire 4 single-file component, routed with Route::livewire().
  • Alpine.js handles the small interactive bits, such as the gallery lightbox.
  • Invoices are rendered from a Blade view to PDF with DomPDF.
  • A GitHub Actions pipeline runs Pint (code style), Larastan (static analysis) and Pest on every push, and Dependabot keeps dependencies current.
  • Custom error pages for 403, 404, 419, 429 and 500.
